# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.
Предметная область: магазин аксессуаров для учёбы и работы (аудио, гаджеты, аксессуары, товары для дома).

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина: главная, каталог с фильтрами, карточка товара, контакты, модальное окно с формой заявки.

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары, отзывы, FAQ;
- `catalog.html` — каталог товаров с sticky-фильтром по категории, цене и скидке;
- `product.html` — страница товара: изображение, описание, таблица характеристик, отзывы, похожие товары; открывается как `product.html?id=N`;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей (БЭМ, CSS-переменные);
- `js/products.js` — единый список товаров и подстановка данных на страницу товара по `?id=`;
- `js/main.js` — модальное окно, кнопка «Наверх», фильтр каталога, FAQ;
- `images/` — изображения товаров (`product-1.svg` … `product-9.svg`), иллюстрация hero (`hero.svg`), превью для Open Graph (`preview.jpg`);
- `README.md` — описание проекта;
- `sitemap.xml` — карта сайта;
- `.gitignore` — список файлов, исключённых из Git;
- `.gitattributes` — единые переводы строк (LF).

## Как посмотреть проект

1. Открыть опубликованную версию на GitHub Pages (ссылка ниже), либо
2. Склонировать репозиторий и открыть `index.html` в браузере — сборка не нужна.

Что проверить:

- переходы между страницами в меню и по хлебным крошкам;
- якорные ссылки «Популярные товары» и «Вопросы» на главной;
- клик по любой карточке — открывается страница именно этого товара (`product.html?id=N`);
- кнопку «Заказать» в карточке — открывается модальное окно с названием товара;
- отправку пустой формы — ошибки показываются под полями;
- фильтр каталога — список и счётчик обновляются сразу, фильтр остаётся на экране при прокрутке;
- кнопку «Наверх» — появляется после прокрутки на 400 px.

## Самостоятельные доработки (практическая работа 8)

1. **Аккуратная работа с изображениями.** У каждого `<img>` заданы `width`/`height` (нет скачков раскладки при загрузке), осмысленный `alt`, `loading="lazy"` для картинок ниже первого экрана и `fetchpriority="high"` для hero и главного фото товара. Картинки в карточках имеют фиксированное соотношение сторон (`aspect-ratio: 4 / 3`, `object-fit: cover`). Изображения в формате SVG — лёгкие и чёткие на любом экране. На странице товара картинка обёрнута в `<figure>` с `<figcaption>`.
2. **Блок часто задаваемых вопросов** (`faq`, `index.html#faq`) на `<details>`/`<summary>` — работает без JS; JS лишь закрывает остальные вопросы при открытии одного (режим аккордеона).
3. **Фиксированная кнопка «Наверх»** (`to-top`): `position: fixed`, `z-index`, появляется после прокрутки на 400 px, плавная прокрутка с учётом `prefers-reduced-motion`. Есть на всех страницах.
4. **Улучшенное модальное окно** (`order-dialog`): кнопка-крестик (`position: absolute`), название выбранного товара в шапке окна, автоматический выбор темы «Заказ товара», закрытие по клику на подложку и по Esc, фокус на первом поле, тексты ошибок под полями (`order-form__error`, `aria-describedby`), ошибка исчезает при исправлении, анимация появления, сообщение об успехе в виде всплывающего уведомления с названием товара, которое само скрывается.
5. **Более подробная карточка товара** (`product.html`): галерея, категория, бейдж, рейтинг, цена и старая цена, наличие, описание, список особенностей, таблица характеристик (`product-table`), отзывы о товаре, блок «Похожие товары». Страница одна, но показывает любой из 9 товаров: данные лежат в `js/products.js`, нужный товар выбирается по `?id=N` (без параметра — первый товар, разметка по умолчанию заполнена им). У товара «Нет в наличии» кнопка «Заказать» отключена. Карточка в каталоге целиком является ссылкой на свой товар (растянутая ссылка `product-card__link::after`), поэтому отдельная кнопка «Подробнее» не нужна.
6. **Блок отзывов** (`reviews`, `review`) на главной и на странице товара: аватар с инициалами, автор, дата в `<time datetime>`, оценка звёздами с `aria-label`.
7. **Расширенный каталог**: 9 товаров в 4 категориях, бейджи «Хит», «Новинка», «Скидка», «Нет в наличии» (`product-card__badge--*`), старая цена (`product-card__old-price`), модификаторы карточек `--hit`, `--new`, `--discount`, `--out-of-stock`.
8. **Sticky-фильтр каталога**: `catalog-filters` закреплён под шапкой (`position: sticky; top: var(--header-offset)`, `align-items: start` у сетки). Фильтр по категориям, цене и скидке работает на JS: карточки получают `data-category`/`data-price`, счётчик «Показано товаров» и сообщение «ничего не найдено».

Дополнительно: страница товара добавлена в хлебные крошки и `sitemap.xml`; базовые медиазапросы для узких экранов.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root` (цвета, отступы, скругления, тени, слои `z-index`, смещение шапки);
- единая шкала отступов;
- состояния `:hover`, `:focus-visible`, `:active`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- позиционирование: `sticky` (шапка, фильтр), `fixed` (кнопка «Наверх», уведомление), `absolute` (бейджи, крестик модального окна), `relative` (карточка, окно);
- структурированный файл `css/style.css` с пронумерованными разделами.

## Дополнительные элементы

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню, кнопок в карточках, шапки отзыва и рейтинга;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек и сетки отзывов;
- CSS Grid для hero-блока, страницы каталога (фильтры + список) и страницы товара (галерея + описание).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта (`site-header__inner`, `site-header__logo`);
- `site-nav` — основная навигация (`site-nav__list`, `site-nav__item`, `site-nav__link`, модификатор `site-nav__link--active`);
- `breadcrumbs` — хлебные крошки (`breadcrumbs__link`, `breadcrumbs__link--next`, `breadcrumbs__current`);
- `hero` — первый экран главной страницы (`hero__content`, `hero__title`, `hero__text`, `hero__actions`, `hero__image`);
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (`__badge`, `__media`, `__image`, `__category`, `__title`, `__link`, `__description`, `__price`, `__old-price`, `__actions`, `__button`; модификаторы `--featured`, `--hit`, `--new`, `--discount`, `--out-of-stock`, `--hidden`);
- `product` — страница товара (`__gallery`, `__image`, `__caption`, `__summary`, `__title`, `__badge` с модификаторами `--hit/--new/--discount/--muted`, `__rating`, `__price`, `__old-price`, `__availability`, `__features`, `__actions`);
- `product-table` — таблица характеристик (`__caption`, `__head`, `__cell`);
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` и `filters-form` — фильтры каталога (`filters-form__group`, `__legend`, `__label`, `__input`, `__checkbox`, `__count`, `__actions`);
- `catalog-products` — список товаров (`__title`, `__empty`);
- `reviews` и `review` — отзывы (`review__header`, `__avatar`, `__meta`, `__author`, `__date`, `__rating`, `__text`);
- `faq` — вопросы и ответы (`faq__item`, `__question`, `__answer`);
- `to-top` — кнопка «Наверх» (`to-top__icon`, модификатор `--visible`);
- `order-dialog` — модальное окно заявки (`__close`, `__title`, `__product`);
- `order-form` — форма заявки (`order-form__field`, `__label`, `__input`, `__select`, `__textarea`, `__checkbox`, `__hint`, `__error`, `__actions`);
- `button` — кнопка (модификаторы `button--primary`, `button--secondary`, `button--disabled`);
- `success-message` — всплывающее сообщение об успешной отправке;
- `aside-info` — информационный блок;
- `site-footer` — подвал сайта.
